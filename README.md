# Работа с СУБД sqlite3 "Учет книг"
**ВАЖНО:** Данный программный продукт создан в учебных целях, чтобы получить опыт работы с sql
### В разработке использовал:
* Python 
* sqlite3
### Возможности:
* Вы можете внести в БД книгу
* Вы можете внести в БД автора
* Вы можете прочитать все записи (книги) и всех авторов
* Вы можете удалить книгу или автора из базы
> *Примечание В связи с малым учебным опытом для консультации использовал ИИ. Конкретный момент - создание автора, чтобы не было дублей в базе. Книги могут дублироваться.*
